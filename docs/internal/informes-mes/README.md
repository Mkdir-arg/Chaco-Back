# Informes de cierre de mes

Cada archivo es el **texto enviado al cliente** al cerrar un mes, tal cual se
mandó. No se publican en el sitio (`docs_dir` es `docs/client`): son el registro
interno y, sobre todo, la **referencia de tono y formato** para el siguiente.

`/pm:informemes` los usa así: el más reciente manda para el formato; el de junio
2026 es el que fijó la estructura (apertura con el cierre de horas, párrafo de
resultados, secciones numeradas y la tabla `Frente | Horas | Participación`).

Un archivo por mes: `AAAA-MM.md`.
