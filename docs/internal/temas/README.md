# Temas — documentos internos por tema

Un `.md` por tema: integraciones, definiciones técnicas y material de referencia
que no es un requerimiento (eso vive en [`../requerimientos.md`](../requerimientos.md))
ni documentación pública (eso vive en `docs/client/`).

**Claves y credenciales: nunca acá.** Este directorio está en git (visible para
todo el equipo y para siempre en el historial). Las credenciales van al gestor de
claves del equipo y a las variables de entorno del servidor; los documentos solo
referencian *dónde* están y *quién* las entregó.

> `docs/` está excluido del snapshot de release (`.gitattributes`), así que nada
> de esto viaja a `main` ni al espejo de ECOM.
