## Pedido original
La auditoría del PR #1387 (Cambio 593) dejó un MINOR: `_origen` toma el `netloc` de `APP_CAMPO_URL` tal cual. Un valor mal cargado (`https://*`, `https://a.ar;worker-src *`, `https://a.ar b.ar`) abriría `form-action` a cualquier host o metería directivas en la política.

## Alcance acordado
**Entra:** validar el host antes de sumarlo a `form-action`. **Queda afuera:** el correo y la redirección siguen usando `APP_CAMPO_URL` tal como está cargada.

## Decisiones tomadas
1. El host tiene que calzar entero con `[A-Za-z0-9.-]+(:\d{1,5})?`: sin comodín, espacios, `;` ni usuario:clave. Si no calza, `form-action` queda en `'self'`.
2. Los valores documentados (`https://datanach-app.ecomdev.ar`, `https://datanach-app.chaco.gob.ar`) y un host con puerto siguen entrando.

## Implementación
