Hacen falta las DOS para mostrar coordenadas y enlace; con una sola, o con ninguna, se muestra el estado vacío. Un 0 cuenta como cargada: si el modelo usa 0 por defecto en vez de null, el bloque va a mostrar «0,000000 / 0,000000» y enlazar a Null Island. Hay que pasar None, no 0. plano_url opcional: enlace al plano del edificio. Se muestra **aunque no haya coordenadas** — son dos datos independientes y uno no esconde al otro. Tiene que ser la URL de un archivo adjunto (FileField.url), no una URL libre: el autoescape protege del marcado, pero no de un esquema `javascript:`. plano_nombre texto del enlace del plano; por defecto «Plano del edificio». El enlace «Ver en el mapa» abre OpenStreetMap en una pestaña nueva: no carga nada dentro de la página, así que no hace falta tocar la CSP ni cargar librerías de mapas. Por ese enlace, el prefijo `https://www.openstreetmap.org/?mlat=` figura entre los permitidos de la prueba `SinRecursosDeTercerosTests` de `portal/tests/`, que es la red que impide volver a traer código de un CDN: si se cambia de proveedor hay que actualizar esa lista. {% endcomment %}{% load l10n %}
