{% load static %} {% comment %} Alta rápida de usuario (coordinador / referente / territorial) desde las pantallas de Becas. Modal canónico: panel role=dialog, encabezado con X, cuerpo desplazable y pie gris. El cierre (X, Cancelar, backdrop, Escape) lo resuelve este mismo script con [data-quick-user-close], para no quedar encerrado si becas-modal.js no llega a cargar (bloqueado o 404). Si becas-modal.js está disponible, además se usa becasModal.bind para el foco inicial y la trampa de Tab (no para cerrar). Contrato: POST a users:usuario_alta_rapida, respuesta data.user. Para tipo=territorial el modal abre en un paso previo de búsqueda (users:usuario_buscar_territorial): si la persona ya tiene cuenta se le suma el segmento (users:usuario_asignar_territorial) en vez de crear otra; si no está, "Crear territorial nuevo" pasa al formulario de siempre, precargado con lo tipeado. Coordinador y referente abren directo en el formulario. Un solo role=dialog con dos paneles; el paso se alterna con la CLASE hidden (un contenedor .flex le gana al atributo [hidden]). No reutiliza programas/becas/_modal_header.html ni _modal_footer.html: esos parciales cierran solo vía data-becas-modal-cerrar (dependencia dura de becas-modal.js) y viven en la app programas, mientras este modal es de la app users y necesita seguir funcionando sin ese script. {% endcomment %}
